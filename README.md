# qualChit

Приложение для автоматизации формирования пакета экзаменационных
документов в области неразрушающего контроля сварных соединений
(ВИК, РК, УК и т.д.).

Пользователь вводит параметры экзамена, прикладывает файлы для
трансформации — на выходе получает готовый ZIP-архив с заполненными
документами и корректными именами файлов.

Подробный контекст проекта — в [CLAUDE.md](./CLAUDE.md).

## Структура

```
frontend/        React-приложение (Vite), форма ввода данных
backend/          Express-сервер, приём данных и файлов, трансформация
backend/transformers/   модули трансформации документов (по одному на тип)
library/          заготовки документов по методам контроля (ВИК, РК, УК)
```

## Запуск локально

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

### Backend

```bash
cd backend
npm install
npm run dev
```

Сервер поднимется на http://localhost:3001
